# Personal Portfolio Website

A clean, professional portfolio website inspired by Beautiful Jekyll.

## Structure

- `index.html` - Main landing page with social links
- `research.html` - Research interests and projects
- `profile.html` - Professional profile and education
- `about.html` - Personal background and interests
- `publications.html` - List of publications
- `contact.html` - Contact information
- `styles.css` - All styling for the website

## Customization

To personalize this website for yourself:

1. **Update Personal Information**: Replace "Your Name" with your actual name in all HTML files
2. **Update Email**: Change `your.email@example.com` to your email address
3. **Update Social Links**: Replace placeholder URLs with your actual social media profiles:
   - GitHub: `https://github.com/yourusername`
   - LinkedIn: `https://linkedin.com/in/yourusername`
   - ORCID: `https://orcid.org/your-orcid-id`
   - Google Scholar: `https://scholar.google.com/citations?user=yourID`
   - Calendly: `https://calendly.com/yourusername`

4. **Add Your Resume**: Place your resume PDF in the root directory as `resume.pdf`

5. **Update Content**: Edit each page with your actual:
   - Research interests and projects
   - Education and professional experience
   - Publications
   - Personal background
   - Contact information

## Deployment

### GitHub Pages
1. Create a repository named `yourusername.github.io`
2. Push all files to the repository
3. Your site will be available at `https://yourusername.github.io`

### Local Testing
Simply open `index.html` in your web browser to preview the site locally.
